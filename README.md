# Mod HD para Port Royale 2

<img src="examples/00-splash.jpg" alt="Port Royale 2 a 1920×1080" width="1280">

Mod para **«Port Royale 2: Imperio y Piratas»** (edición
española de FX Interactive) para jugar a **1920×1080** con la interfaz
recolocada para pantallas 16:9.

- Resolución 1920×1080 usando `PR2_HD`.

`PR2.exe` sigue funcionando
como siempre a 1024×768.

## Requisitos

- Una copia legítima de **Port Royale 2: Imperio y Piratas** de **FX
  Interactive**, con el ejecutable `PR2.exe` versión **1.1.2.44**.
- Windows, o Linux con Wine/Lutris.

> [!IMPORTANT]
> Las versiones de GOG y Steam (en inglés, `PR2.exe` 1.1.2.3) **no son
> compatibles**.

## Instalación

1. Descarga el `.zip` de la última versión en
   [Releases](../../releases).
2. Haz una copia de seguridad de `Videos\intro.wmv` si quieres conservar la
   intro original (el mod la sustituye por el mismo vídeo escalado).
3. Descomprime el `.zip` **en la carpeta de instalación del juego**, la que
   contiene `PR2.exe` (por ejemplo `C:\Program Files\Port Royale 2`).
   Acepta reemplazar `Videos\intro.wmv`.
4. Juega lanzando **`PR2_HD.exe`** en lugar de `PR2.exe`:

## Desinstalación

Borra `PR2_HD.exe`, `hd.dll` y `pr2_patch.cpr`. Si guardaste la intro
original, vuelve a copiarla en `Videos\`.

## Problemas conocidos

- La interfaz está diseñada para 1024 px.
- No hay escalado de interfaz. Se han aumentado los tamaños de textos +2px, donde ha sido posible.
- Alguna pantalla puede mostrar un texto recortado o quedar
  descolocada. Se han corregido las encontradas en las pruebas.
